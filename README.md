# Gabinet Kosmetyczny Anette

Strona internetowa dla Gabinetu Kosmetycznego Anette (anette.beauty).

## Struktura projektu

- `index.html`: Strona główna
- `_nav.html`: Komponent nawigacji (wstrzykiwany dynamicznie)
- `_footer.html`: Komponent stopki (wstrzykiwany dynamicznie)
- `assets/`: Pliki statyczne (CSS, JS, obrazy)
- `pages/`: Podstrony serwisu

## Uruchomienie

Projekt wykorzystuje `fetch` do ładowania komponentów, dlatego do poprawnego działania lokalnie wymagany jest serwer lokalny (np. rozszerzenie "Live Server" w VS Code). Otwarcie pliku bezpośrednio z dysku może powodować błędy CORS.

## Technologie

- HTML5, CSS3, JavaScript
